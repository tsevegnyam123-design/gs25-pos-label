# GS25 CFF — POS шошго хэвлэх

SEWOO SLK-TS400 (80 мм roll paper) принтерт зориулсан нэг файлтай веб.

## Ашиглах
1. GitHub Pages-ээр нийтэлсний дараа веб хаяг руу орно.
2. Жагсаалтаас 8 барааны аль нэгийг сонгоно.
3. Веб төхөөрөмжийн тухайн мөчийн цагаар жигнэсэн цагийг тогтооно; болох цагт 60 минут, устгах цагт 6 цаг нэмнэ.
4. Анхдагч тохиргоогоор бараа сонгоход хэвлэх цонх нээгдэнэ. SLK-TS400 принтерээ сонгож 80 мм цаас, 100% масштаб, 0 margin, headers/footers off тохируулна.
5. Хүсвэл автоматаар хэвлэх цонх нээх сонголтыг унтрааж, хэвлэх товчийг ашиглана.

**Чухал:** +1 цаг, +6 цаг нь зөвхөн оруулсан жишээ зурагт байгаа хугацаа. Бүтээгдэхүүний бодит хадгалах болон устгах хугацааг байгууллагын баталсан журмаар тохируулна. Хугацаа маргааш шилжвэл нэмэлт огноо гарна.

## GitHub Pages идэвхжүүлэх
Repository-ийн **Settings → Pages** рүү ороод **Build and deployment → Source: Deploy from a branch → main → /(root) → Save** сонгоно.

Нийтлэгдсэний дараах хаяг: https://tsevegnyam123-design.github.io/gs25-pos-label/

GitHub Pages нь зөвхөн вебийг нээж өгнө. Хэвлэх цонхгүй автоматаар цаас гаргахын тулд принтерийн драйвер болон тусдаа kiosk/print-bridge тохиргоо шаардлагатай.
