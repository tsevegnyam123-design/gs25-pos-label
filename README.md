# GS25 CFF — POS шошго хэвлэх

SEWOO SLK-TS400 (80 мм roll paper) принтерт зориулсан нэг файлтай веб.

## Ашиглах
1. GitHub Pages-ээр нийтэлсний дараа веб хаяг руу орно.
2. Жагсаалтаас 13 барааны аль нэгийг сонгоно. Үүнээс 4 нь хотдог, 1 нь хотдогны соус.
3. Веб төхөөрөмжийн тухайн мөчийн цагаар эхэлсэн цагийг тогтооно. Эхний 8 бараанд болох цаг +60 минут, устгах цаг +6 цаг. Хотдог гич, Хотдог кепчуп, Хотдог /Үхэр/, Хотдог тахиа гэсэн 4 бараанд болох цагийн мөр байхгүй бөгөөд устгах цаг +72 цаг (3 хоног) байна. Хотдогны соус нь тусдаа сонголт, болох цагийн мөргүй, устгах цаг +48 цаг (2 хоног). Дараагийн өдөр рүү шилжихэд тухайн огноо хамт харагдана.
4. Анхдагч тохиргоогоор бараа сонгоход хэвлэх цонх нээгдэнэ. SLK-TS400 принтерээ сонгож 80 мм цаас, 100% масштаб, 0 margin, headers/footers off тохируулна.
5. Хүсвэл автоматаар хэвлэх цонх нээх сонголтыг унтрааж, хэвлэх товчийг ашиглана.

**Чухал:** +1 цаг, +6 цаг нь оруулсан жишээ зурагт байгаа хугацаа; хотдогийн +72 цаг, соусны +48 цаг нь хүссэн тохиргоо. Бүтээгдэхүүний бодит хадгалах болон устгах хугацааг байгууллагын баталсан журмаар тохируулна. Хугацаа маргааш шилжвэл нэмэлт огноо гарна.
